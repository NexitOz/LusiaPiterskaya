# Официальный сайт Люси Питерской

Одностраничный cinematic-лендинг на Next.js, TypeScript, Tailwind CSS и Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Проверки: `npm run lint`, `npm run typecheck`, `npm run build`.

## Контент и медиа

- Весь редактируемый контент, ссылки, релизы и список видео находятся в `data/artist.ts`.
- Обложки и портреты положите в `public/art/` (предпочтительно AVIF/WebP).
- MP4 положите в `public/media/`. Схема именования описана в `public/media/README.md`.
- Для hero-видео можно добавить `/public/media/hero.mp4` и заменить фон hero в `app/page.tsx` на `<video>` с poster. Текущий статичный арт обеспечивает быструю загрузку до получения финального ролика.
