# Официальный сайт Люси Питерской

Одностраничный музыкальный лендинг в концепции «Ночное сияние» на Next.js,
TypeScript, Tailwind CSS и Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Проверки: `npm run lint`, `npm run typecheck`, `npm run build`.

## Контент и медиа

- Весь редактируемый контент, ссылки, релизы и список видео находятся в `data/artist.ts`.
- MP4 находятся в `public/media/`. Один и тот же оригинальный материал артистки
  используется в hero, блоке об артистке и самостоятельном видеоплеере.
- Сайт не загружает внешние шрифты при сборке, поэтому production-сборка
  воспроизводима и в окружениях без доступа к Google Fonts.
